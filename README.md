# Python-LR9: Лабораторна робота 9. Парсинг HTML-сторінок

## Опис проекту
Репозиторій містить виконання Лабораторної роботи №9 з дисципліни Python:
- Базовий рівень: Парсинг за допомогою `requests` та `BeautifulSoup`, витяг посилань та тексту, збереження у `.txt`.
- Середній рівень: Робота з пагінацією, створення датасету (назва, ціна, рейтинг, посилання), фільтрація та експорт у `CSV`.
- Високий рівень: Універсальний клас `BookScraper`, логування, багатопоточний збір даних (`ThreadPoolExecutor`), експорт у `JSON`/`CSV` та unit-тести з `unittest.mock`.
