# Python-LR9: Лабораторна робота 9. Парсинг HTML-сторінок

## Мета роботи
Ознайомитися з основами HTML-парсингу за допомогою мови Python, навчитися отримувати, обробляти та зберігати дані з веб-сторінок, а також опанувати інструменти для автоматизованого збору та тестування даних.

## Об'єкт парсингу
Для виконання лабораторної роботи обрано сайт зі списку рекомендованих:
- **Назва**: [Books to Scrape](http://books.toscrape.com/)
- **Призначення**: Навчальний веб-каталог книг з пагінацією, категоріями, цінами та рейтингами.

## Структура проекту

- `basic_scraper.py` — Базовий рівень: завантаження сторінки через `requests`, розбір HTML за допомогою `BeautifulSoup`, витяг цін, назв та всіх посилань, експорт у `.txt`.
- `medium_scraper.py` — Середній рівень: багатосторінковий збір (пагінація), формування датасету, фільтрація за ціною та рейтингом, збереження у `CSV`.
- `advanced_scraper.py` — Високий рівень: універсальний клас `BookScraper`, логування у файл та консоль (`logging`), багатопотоковий парсинг (`ThreadPoolExecutor`), експорт у `JSON` та `CSV`.
- `test_scraper.py` — Модульні тести для класу `BookScraper` з використанням `pytest` та `unittest.mock` (покриття 95%).
- `scraped_data.txt` — Текстовий звіт базового рівня.
- `books_dataset.csv` — Повний CSV-датасет середнього рівня (60 книг з перших 3 сторінок).
- `filtered_books.csv` — Відфільтрований CSV-датасет середнього рівня (книги з ціною >= 30.0 та рейтингом >= 4 зірки).
- `advanced_books.json` / `advanced_books.csv` — Датасет високого рівня (100 книг з 5 сторінок, зібраних багатопотоково).
- `top_rated_books.json` / `top_rated_books.csv` — Відфільтровані преміум-книги високого рівня (ціна > 40.0, рейтинг 5 зірок).
- `scraper.log` — Журнал роботи багатопотокового парсера.

## Опис виконаних рівнів

### А. Базовий рівень
- Використано бібліотеки `requests` та `BeautifulSoup`.
- Реалізовано завантаження сторінки з коректним автовизначенням кодування UTF-8.
- Вилучено заголовок сторінки, книги та 94 посилання (`<a href="...">`) з автоматичним приведенням їх до абсолютних адрес за допомогою `urljoin`.
- Збережено результати у структурованому вигляді у файл `scraped_data.txt`.

### Б. Середній рівень
- Реалізовано обхід пагінації каталогу (`catalogue/page-{page}.html`).
- Зібрано структуровані дані у форматі списку словників (`title`, `price` типу `float`, `rating` типу `int`, `availability`, `link`).
- Збережено результати у формат `CSV` (`books_dataset.csv`).
- Реалізовано фільтрацію за ціною та рейтингом зі збереженням у `filtered_books.csv`.

### В. Високий рівень
- **Клас `BookScraper`**: інкапсулює всю логіку підключення, завантаження, парсингу, фільтрації та експорту.
- **Логування**: застосовано стандартний модуль `logging` з одночасним записом у консоль та файл `scraper.log` (фіксація успішних завантажень, помилок 404/500, тайм-аутів та часу роботи).
- **Багатопоточність**: прискорення збору даних за допомогою пулу потоків `concurrent.futures.ThreadPoolExecutor` (5 сторінок / 100 книг обробляються менш ніж за 2 секунди).
- **Експорт даних**: додано методи класу `save_to_json()` та `save_to_csv()`.
- **Unit-тести**: 19 тестів у `test_scraper.py` з повним мокінгом мережевих та файлових операцій (`unittest.mock`), що забезпечують 95% тестового покриття.

## Інструкція запуску

### Запуск скриптів
```bash
# Базовий рівень
python basic_scraper.py

# Середній рівень
python medium_scraper.py

# Високий рівень (багатопоточний клас)
python advanced_scraper.py
```

### Запуск тестів та перевірка покриття
```bash
# Запуск тестів
pytest -v

# Запуск з розрахунком покриття коду
pytest test_scraper.py --cov=advanced_scraper --cov-report=term-missing
```
